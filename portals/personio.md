# Personio

Seen at: several startups.

The best case so far: on 20 Aug 2026 an entire application was completed
programmatically. Personio exposes real file inputs and plain form fields, so
`read_page` plus batched `form_input` plus `file_upload` covers the whole form.

- No account needed.
- Salary: use the figure recorded in `master-profile.yaml`; never change it without asking.
- An "available until" field can be built from your stated minimum commitment
  (`availability.minimum_commitment` in the profile).
